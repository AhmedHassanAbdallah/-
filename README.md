# Kitchen Studio – مصمم المطابخ الذكي

تطبيق للهواتف يتيح لأي شخص تصميم مطبخه من الصفر: رسم الغرفة، توزيع الوحدات والأجهزة، اختيار الخامات والألوان، مشاهدة المطبخ ثلاثي الأبعاد والتجول داخله، ثم الحصول على التكلفة التقديرية والمخططات التنفيذية وقوائم القص.

يعمل التطبيق بالكامل على الجهاز: بدون إنترنت، بدون حساب، وبدون أي خوادم.

## تنزيل التطبيق (APK)

**[تنزيل KitchenStudio.apk](https://github.com/AhmedHassanAbdallah/-/releases/download/latest-apk/KitchenStudio.apk)**

يُبنى ملف الـAPK تلقائياً مع كل تحديث للكود وينشر في صفحة
[الإصدارات](https://github.com/AhmedHassanAbdallah/-/releases/tag/latest-apk).

للتثبيت: نزّل الملف على الهاتف، افتحه، واسمح بالتثبيت من هذا المصدر عند السؤال (Android 7 أو أحدث).
النسخ الأحدث تُثبَّت فوق القديمة دون فقد المشاريع المحفوظة.

## المميزات

**الغرفة**
- أشكال جاهزة (مستطيل، حرف L، غرفة ببروز) مع سحب الأركان وتقسيم الحوائط لأي شكل.
- أبواب وشبابيك وأعمدة خرسانية، ونقاط المياه والصرف والكهرباء والغاز.

**التصميم ثنائي الأبعاد**
- مكتبة وحدات: سفلية، علوية، أدراج، أركان، جزيرة، أعمدة فرن وثلاجة ومؤن، وأجهزة.
- سحب باللمس مع التصاق تلقائي بالحوائط والوحدات المجاورة، وتنبيه عند التداخل أو سد باب أو شباك.
- تعديل كامل لكل وحدة: الأبعاد، تقسيم الواجهة (ضلف، أدراج، قلاب، زجاج، فرن…)، الأرفف، اتجاه المفصلات، الحوض والمسطح.
- حفظ أي وحدة معدّلة في «وحداتي» لإعادة استخدامها.
- تراجع وإعادة.

**العرض ثلاثي الأبعاد**
- دوران وتكبير حر، مسقط علوي، واجهات الحوائط، ووضع التجول داخل المطبخ.
- خامات واقعية تُولَّد على الجهاز: خشب، رخام، جرانيت، كوارتز، بلاط.
- حفظ صورة للمشهد.

**فتح الضلف والأدراج**
- زر في العرض ثلاثي الأبعاد يفتح كل الضلف والأدراج والقلابات بحركة، أو افتح وحدة واحدة بعد اختيارها، لترى الأرفف وصناديق الأدراج ومنظم الملاعق وسحّابة التوابل من الداخل.

**ديكور وإضاءة**
- فاترينة زجاج بإطار أسود وجوانب زجاج، نيش مضيء، صف علوي زجاج، عمود أرفف مفتوح، بانوه خشب مضلّع، بار بسطح شلال، وإضاءة معلقة.
- إضاءة LED بروفايل داخل الوحدة أو أسفلها لكل وحدة على حدة، وضلف مضلّعة.

**الخامات والتشطيبات**
- ضلف MDF لاكيه، HPL، PVC، أكريليك، وقشرة خشب — لكل من السفلي والعلوي والأعمدة أو لوحدة بعينها.
- أسطح العمل، تجليد الحائط، المقابض، الوزرة، ألوان الحوائط والأرضيات، وإضاءة LED.
- ستايلات جاهزة متناسقة بضغطة واحدة.

**المساعد الذكي**
- يقترح توزيعاً كاملاً (خطي، حرف L، حرف U) حسب أبعاد الغرفة وأماكن الأبواب والشبابيك ومصادر المياه والغاز.
- تختار كل الأجهزة الموجودة عندك فيوزعها في أماكنها المناسبة.
- يعمل بقواعد هندسية على الجهاز نفسه دون إنترنت.

**الحسابات**
- أطوال الوحدات وسطح العمل، مساحة الضلف، شريط الحرف.
- قائمة قص كاملة حسب قواعد التصنيع (سماكات، فواصل، وزرة، مجاري أدراج…) مع تعديل القواعد.
- عدد الألواح بتوزيع فعلي للقطع على اللوح، وكميات المفصلات والمقابض والمجاري والأرجل وغيرها.
- تكلفة تقديرية بأسعار قابلة للتعديل، مع هامش ربح وضريبة، وحفظها كأسعار افتراضية.

**المخططات التنفيذية**
- ملخص المشروع، المسقط الأفقي بالأبعاد، واجهات الحوائط، جدول الوحدات، تفاصيل كل وحدة (واجهة وقطاع وقطع)، قائمة القص، مخطط توزيع القطع على الألواح، وقائمة الخامات والتكلفة.
- تصدير PDF، صور، نماذج ثلاثية الأبعاد (GLB و OBJ)، وقائمة القص CSV.

**إدارة المشاريع**
- مشاريع متعددة تُحفظ تلقائياً، نسخ، إعادة تسمية، مقارنة حتى 4 تصميمات، وتصدير واستيراد ملف المشروع.
- واجهة عربية وإنجليزية.

## ملاحظات مهمة

- الأسعار الافتراضية استرشادية فقط؛ عدّلها من «الحسابات ← الأسعار» لتطابق السوق عندك.
- عدد الألواح ومخطط التوزيع تقدير جيد للشراء، وليس بديلاً عن برنامج المنشار عند التقطيع.
- راجع المقاسات على الطبيعة قبل التصنيع.

## للمطورين

المتطلبات: Node.js 22 أو أحدث.

```bash
npm install
npm run dev        # تشغيل التطبيق في المتصفح
npm test           # اختبارات المنطق الهندسي والحسابات
npm run build      # فحص الأنواع وبناء نسخة الإنتاج في dist/
```

بناء الـAPK محلياً (يتطلب JDK 21 و Android SDK 36):

```bash
npm run android:apk
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

### بنية المشروع

| المسار | المحتوى |
| --- | --- |
| `src/lib/` | المنطق: هندسة الغرفة والالتصاق، مكتبة الوحدات، قطع القص، توزيع الألواح، التكلفة، المساعد |
| `src/three/` | محرك العرض ثلاثي الأبعاد (three.js): الخامات، بناء الوحدات، المشهد والكاميرا |
| `src/drawings/` | مولّد اللوحات التنفيذية وتصدير PDF |
| `src/ui/` | شاشات التطبيق (React) |
| `src/store.ts`, `src/db.ts` | الحالة والحفظ المحلي (IndexedDB) |
| `android/` | مشروع Android (Capacitor) |
| `.github/workflows/android.yml` | بناء ونشر الـAPK تلقائياً |

ملف `android/app/debug.keystore` مفتاح توقيع تجريبي مشترك حتى تحمل كل النسخ التوقيع نفسه.
للنشر على متجر التطبيقات استخدم مفتاحاً خاصاً بك غير مرفوع في المستودع.

## English summary

Kitchen Studio is an offline-first kitchen design app for Android (React + three.js, packaged with Capacitor).
Draw the room, place cabinets and appliances with touch snapping, pick finishes, explore the result in 3D
(orbit or walk-through), and get quantities, a cost estimate, a cut list with sheet nesting, and working
drawings exportable as PDF, images, GLB/OBJ and CSV. All data stays on the device.

- **APK:** <https://github.com/AhmedHassanAbdallah/-/releases/tag/latest-apk> (rebuilt by CI on every push)
- **Develop:** `npm install && npm run dev` · **Test:** `npm test` · **Build:** `npm run build`
- **APK locally:** `npm run android:apk` (JDK 21 + Android SDK 36)
